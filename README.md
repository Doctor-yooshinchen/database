# 昕博士（陈宇昕）历史语言学数据库（公开版 beta 0.3）

Dr. Yuxin Chen's Historical Linguistics Database · チェン・ユーシン（陳宇昕）博士 歴史言語学データベース · 진위신 박사 역사언어학 데이터베이스

> **公开测试版 beta 0.3。** 内容仍在审定中，拟音、分域和统计数字都可能在以后的版本里改动。引用时请注明版本号“beta 0.3”。各版本改了什么，见首页“历史更新”。

一个单文件、可离线使用的上古汉语谐声与韵母演变查询工具。以陈宇昕博士论文（2025）的上古拟音为主，并列白沙（Baxter & Sagart 2014）与郑张尚芳的拟音，可以按声符、谐声域、韵部、声母演变查看，并列出例外。

## 怎么用

下载 `index.html`，用浏览器（Chrome、Edge、Safari、Firefox 新版）直接打开即可，不需要联网，也不需要安装。文件约 17 MB，字体已内嵌，第一次打开需要几秒钟。

## 主要功能

- **首页与界面语言**：打开后先进首页（库名、简介、查字框、历史更新、致谢），右上角可切换中文、English、日本語、한국어。界面文字随语言切换；韵部名、汉字、中古音韵地位一律保持繁体中文。网址末尾加 `#xs` 可直接进入谐声查询。
- **侧栏**：声母类、韵部、筛选条件、声符索引都在左侧的“侧栏”里，对所有页面有效。
- **声符系列**：输入声符或任一字，按中古声母分栏列出该声符的所有读音，显示谐声域、韵部、字表/类推/待定的数量和例外。点字可以看各家拟音、反切、《广韵》释义和同源词备注；“字图／展开”切换按中古声母排的字图和全部读音的表格。
- **谐声域**：按上古声母类（锐音、钝音及交替域）看整类的中古分布。
- **韵部**：按韵部看各等、各条件下的演变路径，与演化规则表对照。
- **声母演变**：按上古基本声母看中古声母的分布。
- **例外表**：列出声母与谐声域不合、韵母不合规则的字，点开显示为什么算例外、期待的中古地位和可能的原因。
- **上古音节表**：陈氏拟音按“前置辅音 × 基本声母 × 介音 × 韵部”排成表，入声部的次入（\*-Cs）可单独选；点格子看这一类字对应的中古声母和韵。
- **拟音检索**：用下拉菜单选陈氏拟音的前置辅音、基本声母、介音、韵部（如 \*s- + \*l），三家并列显示各自对应的中古声母，以及同一批字别家怎么拟；也可手动输入拟音片段查韵母、韵尾。
- **中古倒查**：选一个中古声母或韵（如以母），看它在陈氏拟音里来自哪些上古来源（如 \*l、\*ɢ），各来源有哪些声符。
- **押韵查询**：《诗经》298 篇、1,778 个韵段（白一平 1992 分组）。可以按篇章读诗（韵脚上色，下标两家拟音和韵部）、查一个字在哪些韵段入韵和谁押、看每一部的独用与合韵；“看陈／看白一平／全看／比较”四档切换，比较时标出两家判断不同的韵段。谐声页的字卡上可以直接跳到押韵。
- **简体字检索**：输入简体字也能查到繁体字；一个简体对应几个繁体时（如 发 → 發、髮）列出来让你选。
- **\*-r 韵尾开关**：关闭后，*-r 部的字按中古韵尾临时并入 -n 部或 -l 部（只改显示）。

## 数据与方法（简述）

- 陈氏拟音：字表 1721 个读音为博士论文所收（个别经作者改订）；其余 15858 个读音按论文第五章的演变规则（共 499 条）和谐声域类推，标“推”，**未经逐字审定**；其中魚 鐸 陽、侯 屋 東、支 錫 耕 九部已按审定的演变规则逐字校订。470 个读音暂时不给拟音，标“待定”（包括只有一至三个字的极少数例外）。
- 韵母例外一律在同一声符、同一谐声域、同声母同等（或同等）之内比较中古韵。
- 谐声域检验：以“中古声母＋韵类（不计声调）”为单位，与零散偏离的背景率比较，二项检验 k≥2 且 p<0.05 才单立一域，否则作例外。
- 禪母即常母，本库一律作常母。

## 已知限制

- 类推出来的拟音没有逐字审定，可能有错。
- 470 个读音待定。
- 少数私用区（PUA）字尚未换成标准 Unicode。
- 除魚 鐸 陽、侯 屋 東、支 錫 耕 九部外，其余韵部的演变规则还在逐部审定。
- 点开字后的长段说明（例外原因、检验备注、广韵释义）目前只有中文。
- 日本、韩国汉字音尚未收入。
